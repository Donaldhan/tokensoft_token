# 合约模块参考

本文档提供各 Capability 与 Role 模块的状态变量、事件与公开 API 速查。

---

## Role 模块

所有 Role 模块均基于 OpenZeppelin `Roles.sol`，由 Owner 管理成员。

### OwnerRole

**文件：** `contracts/roles/OwnerRole.sol`

| 方法 | 权限 | 说明 |
|------|------|------|
| `isOwner(account)` | 公开 | 查询是否为 Owner |
| `addOwner(account)` | onlyOwner | 添加 Owner |
| `removeOwner(account)` | onlyOwner | 移除 Owner |

**事件：** `OwnerAdded`, `OwnerRemoved`

---

### MinterRole / BurnerRole / PauserRole / RevokerRole

**文件：** `contracts/roles/MinterRole.sol` 等

模式一致：

| 方法 | 权限 | 说明 |
|------|------|------|
| `isXxx(account)` | 公开 | 查询角色 |
| `addXxx(account)` | onlyOwner | 添加成员 |
| `removeXxx(account)` | onlyOwner | 移除成员 |

对应 modifier：`onlyMinter`, `onlyBurner`, `onlyPauser`, `onlyRevoker`

---

### WhitelisterRole

**文件：** `contracts/roles/WhitelisterRole.sol`

继承 OwnerRole，提供 `onlyWhitelister` 修饰符及 Whitelister 成员管理。

---

### BlacklisterRole

**文件：** `contracts/roles/BlacklisterRole.sol`

继承 OwnerRole，提供 `onlyBlacklister` 修饰符及 Blacklister 成员管理。

## Capability 模块

### Whitelistable

**文件：** `contracts/capabilities/Whitelistable.sol`

**状态变量：**

| 变量 | 类型 | 说明 |
|------|------|------|
| `isWhitelistEnabled` | bool | 白名单全局开关 |
| `addressWhitelists` | mapping(address => uint8) | 地址所属白名单（0=未分配） |
| `outboundWhitelistsEnabled` | mapping(uint8 => mapping(uint8 => bool)) | 出站路由表 |

**公开方法：**

| 方法 | 权限 | 说明 |
|------|------|------|
| `checkWhitelistAllowed(sender, receiver)` | view | 检测是否允许转账 |
| `setWhitelistEnabled(enabled)` | onlyOwner | 开关白名单 |
| `addToWhitelist(addr, whitelistId)` | onlyWhitelister | 添加地址到白名单 |
| `removeFromWhitelist(addr)` | onlyWhitelister | 从白名单移除 |
| `updateOutboundWhitelistEnabled(src, dst, enabled)` | onlyWhitelister | 配置出站路由 |

**事件：** `AddressAddedToWhitelist`, `AddressRemovedFromWhitelist`, `OutboundWhitelistUpdated`, `WhitelistEnabledUpdated`

## 主合约 API 汇总

### TokenSoftToken（V1 基类）

**文件：** `contracts/TokenSoftToken.sol`

| 方法 | 说明 |
|------|------|
| `initialize(owner, name, symbol, decimals, initialSupply, whitelistEnabled)` | 初始化（仅一次） |
| `detectTransferRestriction(from, to, amt)` | ERC1404 限制检测 |
| `messageForTransferRestriction(code)` | ERC1404 错误消息 |
| `transfer(to, value)` | 受限转账 |
| `transferFrom(from, to, value)` | 受限授权转账 |
| `updateCodeAddress(newAddress)` | 升级逻辑合约 |

### TokenSoftTokenV2

**文件：** `contracts/TokenSoftTokenV2.sol`

继承 V1 全部 API，额外：

- 覆盖 `detectTransferRestriction`：增加黑名单检测（错误码 3）
- 覆盖 `messageForTransferRestriction`：增加黑名单错误消息
- 覆盖 `transfer` / `transferFrom`：解决多重继承冲突
- 继承 `revokeToAddress`（来自 RevocableToAddress）

## ERC1404 接口

**文件：** `contracts/ERC1404.sol`

```solidity
function detectTransferRestriction(address from, address to, uint256 value)
    public view returns (uint8);

function messageForTransferRestriction(uint8 restrictionCode)
    public view returns (string memory);
```

## Proxy

**文件：** `contracts/Proxy.sol`

- 构造函数接收逻辑合约地址并写入 PROXIABLE 存储槽
- `fallback()` 通过 `delegatecall` 转发所有调用到逻辑合约
- 不实现任何业务逻辑，仅做 delegate 代理
